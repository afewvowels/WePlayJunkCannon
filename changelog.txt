Version: 0.2.0
Date: 2026-11-04
  Major Features:
    - First public alpha.
  Features:
    - Startup settings for shell damage, fire cooldown, range and bake time.
    - Shots now have a muzzle flash and hit sparks.
    - Works on Space Age space platforms (platform build and mine events).
  Changes:
    - The hidden cannon is no longer invulnerable. Damage it takes is passed to the furnace,
      so enemies can no longer get stuck attacking an unkillable turret.
    - The 10-shell buffer now uses the furnace's own "Output full" stop instead of pausing it by script.
    - Mining a Junk Cannon returns the shell chambered in the cannon.
    - Inserters can no longer put shells straight into the hidden cannon.
    - Junk recipes now cover every item type the game knows, and skip parameter items.
  Bugfixes:
    - Furnaces paused by 0.1.x scripts are un-paused when loading an old save.
